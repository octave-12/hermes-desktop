## 简介

聊天功能模块是 Hermes 桌面应用的核心组件，为用户提供与 Hermes Agent 进行智能对话的界面。该模块实现了完整的聊天体验，包括消息渲染、实时流式响应、工具调用显示和会话管理等功能。

系统采用前后端分离架构：前端使用 Vue 3 + TypeScript 构建用户界面，后端使用 Python FastAPI 提供 WebSocket 服务。通过 Electron 将两者集成到桌面应用程序中。
